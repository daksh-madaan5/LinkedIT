## 1. `POST /api/optimize`

Solves a Capacitated Vehicle Routing Problem with optional time windows and returns optimized routes.

- **Headers**: `Content-Type: application/json`
- **Accept**: `application/json`

## 2. Error Response Payload Format

All HTTP error responses generated by [`ApiExceptionHandler.java`](file:///d:/Study/SIH/LinkedIT/routing-backend/src/main/java/com/linkedit/routing/controller/ApiExceptionHandler.java) follow a standardized format:

```json
{
  "code": "ERROR_CODE",
  "errors": [
    "Error description detail line 1",
    "Error description detail line 2"
  ]
}
```

### HTTP Error Status Code Mapping

| HTTP Status | Error Code (`code`) | Trigger Condition |
| :--- | :--- | :--- |
| `400 Bad Request` | `INVALID_REQUEST` | Validation error thrown by `OptimizationRequestValidator` (e.g. duplicate IDs, capacity $\le 0$, coordinates out of bounds). |
| `400 Bad Request` | `INVALID_JSON` | Malformed JSON request body or JSON type mismatch. |
| `502 Bad Gateway` | `ROUTING_PROVIDER_FAILED` | External OSRM service failure (connection timeout, unreachable server, HTTP error, unroutable coordinates). |
| `500 Internal Server Error` | `OPTIMIZATION_FAILED` | Internal error in jsprit optimization solver execution. |
